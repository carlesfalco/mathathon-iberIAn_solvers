# Submission package boundary

This GitHub repository is the **supplementary code, figures, data, and results package** for Problem 29.

- [`consolidated/`](consolidated/) contains the consolidated numerical code, figures, data, results, and verification receipts.
- [`presentation.pdf`](presentation.pdf) is the current slide deck; [`presentation.tex`](presentation.tex) is its LaTeX source snapshot.
- [`consolidated/report.tex`](consolidated/report.tex) and [`consolidated/report.pdf`](consolidated/report.pdf) are report snapshots. The official report and final slide wording remain authoritative in the **Final Report** chat.
- Compiled PDFs are reference artifacts, not separate editable workstreams.
- Every numerical or performance claim used in the report should identify its implementation, parameters, and verification receipt under `consolidated/`.

Before submission, synchronize the report and slide snapshots with the report workstream, run the relevant checks in `consolidated/`, and submit the full commit hash of the exact supplementary version selected for judging. Confirm that every numerical or performance claim is supported by this package and that the organizers can access the repository.
