# Compiled reference documents and figures

This directory retains compiled reference material and speaker notes only:

- `report.pdf`: 31-page common-block-strategy report.
- `slides.pdf`: ten core frames plus three backup frames.
- `speaker-notes.md`: narration, timings, transitions, and backup answers.
- `figures/`: figures generated from the included numerical data.

LaTeX sources and report-only build scripts are intentionally not tracked in this supplementary code repository. Report editing happens separately in the **Final Report** chat. The figure-generation code and numerical evidence remain available in the parent package.
